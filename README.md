## Executar os notebooks

```bash
git clone https://github.com/EduardoQuero/Profissao-Cientista-de-Dados.git
cd Profissao-Cientista-de-Dados
python -m venv .venv
```

Ative o ambiente virtual e instale as bibliotecas exigidas pelo módulo escolhido. Para a maior parte dos notebooks:

```bash
pip install jupyter pandas numpy matplotlib seaborn scikit-learn
jupyter notebook
```

## Organização do conteúdo

Os módulos estão separados por tema e ordem de estudo. Cada pasta pode conter notebooks, exercícios, datasets e materiais auxiliares. Como este é um repositório educacional, alguns módulos dependem de arquivos locais ou de versões específicas das bibliotecas indicadas na própria atividade.

## Tecnologias

Python, Jupyter, Pandas, NumPy, Matplotlib, Seaborn, scikit-learn, SQL e Streamlit.
